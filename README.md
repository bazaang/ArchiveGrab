ArchiveGrab is a simple but powerful download manager for downloading directly from Archive.org repos. 

The program is a self-contained single .bat file with no installation needed.

1. To use the program simply double click the ArchiveGrab_vX.X.X.bat. It will launch a CMD window and then a PowerShell GUI.
2. From here you paste in the Archive.org link and let it scan for files. 
3. Select the files you wish to download. File to the file type you're looking for if needed.
4. Select a directory to save the files.
5. Click Download.
